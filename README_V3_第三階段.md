# 台股小幫手 V3 — 第三階段

作者：王聖凱｜寒假轉學書審作品

## 新功能
- 模擬投資組合：輸入股票代號、買入價格、股數；以最新可取得日線收盤價估算未實現損益，支援 CSV 匯出。
- 均線交叉回測：前日收盤訊號、次日開盤模擬執行；比較策略與買入持有，顯示最大回撤及交易次數，支援 CSV 匯出。
- 完整保留第二階段的股票查詢、技術分析、比較、選股、自選股與署名。

## 執行
在含 app.py 的資料夾執行：

```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

往頁面下方捲動至「V3 第三階段」。

## 限制
這是學習用模擬工具，不是真實交易系統。投資組合不含費稅、股利、公司行動；回測允許小數股數，未計滑價、股利與最低手續費。Yahoo Finance 日線可能延遲或缺漏。投資組合輸入不會自動永久保存。

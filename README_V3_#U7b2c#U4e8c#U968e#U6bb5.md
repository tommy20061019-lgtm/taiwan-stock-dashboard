# 台股小幫手 V3｜第二階段

**作品署名：王聖凱｜寒假轉學書審作品**

## 新功能

- **多檔股票比較**：一次比較 2～5 檔股票；使用共同交易日的第一個收盤價作為 0% 基準，顯示累積漲跌幅走勢。
- **條件選股**：輸入最多 12 檔股票，依單日漲跌幅、成交量、20 日均線、RSI 範圍篩選，可下載 CSV。
- 保留原版股票查詢、中文化 K 線圖、RSI／MACD／KD、自選股、PNG 匯出、作品署名。

## Windows 執行

1. 解壓縮 ZIP，不要覆蓋 V1 或之前已可運作的 V3。
2. 在 VS Code 選擇「檔案 → 開啟資料夾」，開啟包含 `app.py` 的 `台股小幫手_V3` 資料夾。
3. 在終端機執行：

```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

4. 向下捲動頁面，即可看到「V3 第二階段｜股票比較與條件選股」。

## 資料與計算說明

- 使用 Yahoo Finance 取得歷史**日線**資料，不保證即時，也不構成投資建議。
- 股票比較只取各股票**共同有資料的交易日**，第一天設為 0%，不計入交易費、稅或股利。
- 條件選股只針對使用者輸入的股票清單，**不代表全市場掃描**。
- 20 日均線需要至少 20 筆資料；RSI 採用專案現有計算方式。
- 部分股票中文名稱使用本地對照表；不在對照表內時可能顯示資料來源名稱。
- 若資料來源無回應或網路中斷，可能有股票無法查詢。

## 測試建議

1. 查詢 2330，確認原本 K 線與指標顯示正常。
2. 比較 `2330,2317,0050`，確認折線圖與摘要表出現。
3. 條件選股輸入 `2330,2317,0050`，不勾選條件先執行，再逐一加入篩選條件。
4. 測試 CSV 下載，並確認上方署名仍在。

# 台股小幫手｜台股資料分析專題

**製作者：王聖凱**

## 一、專案動機
以 Python 建立可操作的台股資料分析網站，練習資料取得、整理、技術指標計算、視覺化及策略模擬。

## 二、技術架構
- Python：主要程式語言
- Streamlit：互動式網頁介面
- yfinance：取得 Yahoo Finance 歷史日線資料
- pandas / numpy：資料整理與數值運算
- Plotly：互動式 K 線、成交量及比較圖

## 三、主要功能
1. 股票查詢、中文股票名稱、K 線與均線、成交量、歷史資料。
2. RSI、MACD、KD 技術分析。
3. 自選股、圖表 PNG 匯出。
4. 2～5 檔股票走勢比較、指定清單條件選股與 CSV 匯出。
5. 模擬投資組合損益計算。
6. 均線交叉策略歷史回測、交易紀錄及 CSV 匯出。

## 四、系統限制與風險
- 非即時報價；第三方資料可能延遲、缺漏或調整。
- 模擬投資組合未計入手續費、證交稅、股利及公司行動。
- 回測以收盤訊號、次日開盤模擬成交，允許小數股數；未考慮滑價、流動性、最低手續費、股利等因素。
- 回測中的「買入並持有」為價格基準比較，不代表含全部成本的實際投資績效。
- 程式不提供投資建議，亦不具下單功能。

## 五、操作範例
1. 執行 `python -m streamlit run app.py`。
2. 示範查詢 2330，勾選 RSI／MACD／KD。
3. 比較 2330、2317、0050，展示共同起始日的累積漲跌幅。
4. 在投資組合中輸入測試成本與股數，觀察損益計算。
5. 使用 5 日／20 日均線進行 2 年回測，展示交易紀錄與風險指標。

## 六、開發與測試紀錄
本專案已進行股票查詢、技術分析、比較、選股、模擬投資組合、策略回測及匯出等功能操作測試；另以 Python `unittest` 執行 5 項離線測試並通過。以上為既有測試結果，不代表所有資料與交易情境都已驗證。



# 安裝與測試

1. 用 VS Code 開啟**包含 app.py 的資料夾**。
2. 執行 `python -m pip install -r requirements.txt`。
3. 執行 `python -m streamlit run app.py`。
4. 驗證主畫面、中文署名、K 線與技術指標。
5. 在比較功能輸入 `2330,2317,0050`。
6. 使用模擬投資組合範例確認損益數值。
7. 回測 2330、2 年、短期 5 日／長期 20 日，確認交易紀錄可展開。
8. 執行 `python -m unittest discover -s tests -v` 進行離線計算測試。

注意：離線測試不代表網路資料、PNG 匯出與瀏覽器 UI 都已通過實機驗證。
